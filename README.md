# Nassau Candy Distributor - Supply Chain Analytics Dashboard

## Project Overview
This project analyzes factory-to-customer shipping route efficiency for Nassau Candy Distributor.

## Objectives
- Identify high-volume shipment routes
- Detect potential bottlenecks
- Compare shipping mode performance
- Calculate route efficiency scores
- Build interactive dashboard for live analytics

## Key KPIs
- Total Shipments
- Total Sales
- Average Lead Time
- Delay Rate
- Route Efficiency Score

## Tools Used
- Python
- Pandas
- Plotly
- Streamlit

## How to Run the Application

1. Install dependencies:
   pip install -r requirements.txt

2. Run the dashboard:
   streamlit run app.py

## Key Findings
- California, New York, and Texas are highest shipment states
- Standard Class accounts for majority shipments
- Same Day is fastest shipping mode
- Tennessee identified as minor bottleneck
